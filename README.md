# NumPy & Pandas Data Analysis Exercises

A collection of beginner-friendly exercises for practicing NumPy and Pandas in Python.

## Topics Covered

- NumPy arrays
- Array operations
- Mean and aggregation
- Broadcasting
- Boolean masking
- Handling NaN values
- NumPy Structured Arrays
- Sorting NumPy arrays
- Pandas DataFrames
- GroupBy operations
- Filtering rows
- Missing value handling
- Data normalization

## Exercises

### Exercise 1 - Student Scores

Analyze the scores of 5 students across 4 exams.

Tasks:
- Calculate the average score of each student
- Calculate the average score of each exam
- Use broadcasting to subtract exam averages from the scores
- Find the student with the highest average score

### Exercise 2 - Daily Temperatures

Analyze daily temperatures for 10 days.

Tasks:
- Create a boolean mask for temperatures above 28
- Extract temperatures above 28
- Replace temperatures below 20 with NaN
- Calculate the average temperature without NaN values

### Exercise 3 - Employee Data

Work with employee names, ages, and salaries using a NumPy Structured Array.

Tasks:
- Create a Structured Array
- Calculate the average salary of employees over 30
- Find employees with salaries above the overall average
- Sort employees by salary in descending order

### Exercise 4 - Product Sales

Analyze product sales using a Pandas DataFrame.

Tasks:
- Calculate total sales for each product
- Calculate average sales for each store
- Select sales greater than 140
- Create a normalized sales column

### Exercise 5 - Student Grades

Analyze student grades containing missing values.

Tasks:
- Count missing values in each column
- Replace missing values with the column mean
- Calculate the average score of each student
- Find the student with the highest average

### Exercise 6 - Weekly Sales

Analyze daily sales for two weeks using Pandas.

Tasks:
- Convert the NumPy array to a DataFrame
- Calculate total sales for each week
- Calculate total sales for each day
- Find the day with the highest total sales
- Find days with sales above the overall average
